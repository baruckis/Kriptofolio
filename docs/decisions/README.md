# Decisions

One file per long-lived decision about the product, its data or its distribution. Each record
states the context, the decision, what we explicitly do not do, the consequences and the criteria
that would reopen it. An accepted decision is not edited silently: a change of direction gets a
new record that names the one it supersedes. Technical facts about the legacy app stay in
`BEHAVIOUR.md` and `UPGRADE-NOTES.md`.
